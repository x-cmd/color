# 北欧 —— 这套颜色的来历

---

北欧是一族冷而浅的颜色：雪、霜、冰川、峡湾，再加几抹暖色，它们的存在主要是为了不让页面发冷。
读起来平静、干净、通透——像一间采光好的屋子：白墙、浅木、原色织物。

它也是设计写作里最常被误用的标签之一。"北欧"被用来形容白底加一枝桉树，有时指的是实打实的
中世纪北欧风房间，有时指的则是一个跟北欧毫无关系的网站。

这篇是定义：这个标签到底涵盖什么、从哪来、靠哪四条规矩让颜色彼此成立，以及北欧不是什么。
颜色本身在[色板篇](../02-nordic-palette/cn.md)；和暖那一侧最近的那位邻居的对比在
[北欧 vs 侘寂](../03-nordic-vs-wabi-sabi/cn.md)。

---

## 一、北欧是什么

一套北欧色板不等于"浅色加绿植"。它是一组明确的约束：

- **明度带很高**——所有主色与强调色都落在 `L` 0.63 到 0.94 之间
- **彩度有上限**——不超过 `C` 0.12，而且只有三个颜色接近这个上限
- **四个独立色相**——一个冷蓝灰、一个暖陶土、一个绿、一个黄
- **暖色强调要限量**——饱和的颜色是被配给的，不是平摊的

如果只记得一句，就把最后那条读两遍。北欧整体是冷的，暖色是让它不至于显得像诊所的东西。
它们是调味，不是调色盘的另一半。

这条明度带在暗端也异常窄。北欧所有主色都是浅的：最深的是深峡湾，`L` 0.63；比它更深的只有
文字色，`L` 0.34，而它只用来写字，不做色块。北欧界面里没有深色块。

## 二、它从哪来

### 2.1 一个统称，不是一个学派

没有哪一刻有人宣布成立一个"北欧风格"，背后也没有一群创始设计师。"北欧"是当代的一个标签——
在设计写作里，它从 2000 年代之后才逐渐变成常用词——用来指一组共享地域与气质、而非共享
某种主张的东西。

这个标签底下是几套各自不同的国家语汇。丹麦设计偏重手工、榫接与个体匠人，经典的参照是
二十世纪中叶的丹麦现代家具，后来又靠纸与钢的灯具让丹麦设计在国际上被认出来。瑞典设计先
经过一段理性、工业化的阶段，随后转向更暖、更偏织物的路子。挪威和冰岛的设计往往朝外看——
海事、矿物、稀疏。芬兰的设计长在功能主义传统里，把物件首先当作工具来对待。

它们不是一回事，值得抵抗那种抹平。真正共享的是一种态度而不是一种外观：**形式服从日常使用，
而日常使用也可以是美的。**

### 2.2 被带进日常生活的功能主义

功能主义——物件应当诚实地完成自己的任务，不加装饰，为使用者而造——部分起源于一战之后的重建
与随之而来的住房短缺。它经由丹麦建筑师兼家具设计师 Kaare Klint 等人的工作，以及 1930 年代
芬兰与瑞典的先驱者，传入北欧国家。

北欧真正独特的地方，不在这套主张本身，而在它后来的走向。功能主义没有停在家具展厅里；它进
了厨房、教室、育婴室、夏天的木屋。它变成一种**生活方式**，而不只是一种物件风格。这正是通向
颜色论证的桥：如果日常才是设计应当发生的地方，那么日常的表面——墙、布、陶器——就得扛得住
这套配色。

### 2.3 Hygge 与室内即陈设

与设计谱系并行的，还有一套 *hygge* 的词汇：一个丹麦词，通常译作"温馨"或"惬意"，指的是
围炉相聚、简单舒适带来的愉悦。它在营销里用得很松，作为历史术语其实也相当含糊，但它指向的
想法足够具体、因而有用：一个围绕温暖、柔软、不着急的陪伴与简单乐趣来布置的房间。

这正是最能在色板里看见北欧室内的原因。北欧室内是这一族颜色最可辨认的载体：白或近白的墙、
浅木地板与家具、本色或染得很淡的亚麻与羊毛、釉色低调的陶器——而真正做功的那一件，是若干
摆在浅色之中的暖色物件。灰蓝色的搭毯、锈红的靠垫、芥末黄的台灯。

最后这条细节就是色板的微缩版：**浅而冷的底，加少量暖色。**

## 三、视觉语法

### 3.1 浅而冷的底

所有结构性的部分都是浅的。底色是雪 `#F7F9FA`——不是纯白，但也只差一丝，带一点蓝灰的偏色。
面板和卡片下沉一档，是霜 `#E8EDF0`。分隔线是冰川 `#C9D6DE`。

注意这个偏色的方向。这些不是中性灰；灰被拉向了蓝。在 `C` 0.01 到 0.02 的量级上，好屏幕上它们
和灰色几乎分不出来，但铺成一大片时，那点冷偏色正是让房间像日光而不是像电子表格的东西。

### 3.2 用"染色"代替"中性"

北欧色板不为了灰色而用灰。每一个中性色都是**染出来的**——色相在 230° 上下的蓝灰，彩度压得
极低。结果是中性色和蓝色同属一家，所以一张灰卡和一张蓝卡并排放，谁也不像临时贴上去的。

这条最容易被无意破坏。用真正的灰 `#9B9B9B` 顶替峡湾 `#9FB6C4` 不是一个中性选择；它改变的是
整页的温度，而且因为周围一切都带着偏色，这点改变恰恰看得见。

### 3.3 暖色强调，要有节制

三个颜色负责暖意：陶土橘 `#D9A38F`、桉木 `#A9BC8F`、芥末 `#E3C46A`。它们是全族里唯一有真正
彩度的成员——分别是 `C` 0.07、`C` 0.07 和 `C` 0.12，而芥末是整组里最饱和的一个颜色。

它们的活儿是让冷的底读起来是暖的。实际出现的位置通常是：一个按钮或一个选中态、一行高亮、
一小幅插图、照片里的一只杯子、一个标签。一页里芥末出现三处没问题。如果芥末同时是首屏底色、
卡片描边、按钮填充和图表高亮，这页就已经不是北欧，而是"活泼"了。

### 3.4 留白

最后一条根本不是颜色，却是这个家族被抄的时候最常丢掉的一条。北欧室内有**空间**——不拥挤的
界面、矮的家具、长的视线，以及大量没有东西的墙面。

搬到界面上，就是慷慨的留白、宽的页边距，以及对"同时有多少元素在喊"的约束。北欧色板配上一
个拥挤的版面，读起来不是北欧，是发白——因为浅色已经没有空间可以呼吸，而本来该稀有的暖色，
现在正在跟拥挤的网格抢注意力。

## 四、这些数字

<!-- band:nordic:cn -->
| 维度 | 口径 | 取值 |
| --- | --- | --- |
| 明度 | OKLCH L | 0.63 – 0.94 |
| 彩度 | OKLCH C | 0.01 – 0.12 |
| 色相跨度 | 独立色相数（每 30° 一档） | 4 |
| 平均明度 | OKLCH L 均值 | 0.79 |
| 平均彩度 | OKLCH C 均值 | 0.05 |
| 参考：HSL 饱和度均值 | HSL 口径，粉彩上会明显高估 | 34% |
<!-- /band -->

两个数字承载了大部分意思。`L` 0.63 的明度下限，是这个家族不至于滑进莫兰迪地盘的原因——莫兰迪
最深的主色落在 `L` 0.59，底色也更暖。`C` 0.12 的彩度上限是个上限而不是常态：平均彩度只有
`0.05`，因为色板里大部分成员都待在区间的下沿。北欧既浅、又基本接近灰；它不是"中饱和色加白
底"的那种色板。

另一个要记住的数字是四个色相。只允许四个色相的家族不会漂移，因为无处可去。

## 五、北欧不是什么

- **不是一个历史风格。** 没有哪一份北欧学派宣言和一条传承谱系。"北欧"是当代对几套有交集却
  不等价的民族传统的统称。把它当作一个气质的简称，不要当作出处来引用。
- **不是瑞士中立。** 瑞士中立是刻意无色的——一条灰阶加一个信号色，做功的是版式。北欧与它
  共享纪律与秩序，但北欧让每一个中性色都保留冷蓝的偏色，并放进三个暖色。两者的直接对照见
  [瑞士中立 vs 北欧](../../4-swiss-neutral/03-swiss-neutral-vs-nordic/cn.md)。
- **不是侘寂。** 侘寂是暖的、有质感的、刻意不完美的；它的光来自陶土与木料，而且允许暗。
  北欧的光来自白与蓝，而且平整得有点过头。详见
  [北欧 vs 侘寂](../03-nordic-vs-wabi-sabi/cn.md)。
- **不是给需要紧迫感的品牌用的色板。** 整个家族建立在低彩度与浅明度上。它喊不出来，也没法让
  一个截止日期看起来像截止日期。如果产品需要一种代表"现在就动手"的红，北欧就是错的选择，
  排版再好也救不回来。
