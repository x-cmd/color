# 北欧 vs 侘寂

---

这是全书里最常被搞混的一对，原因不难理解：两者都是低彩度，都安静，都靠"克制"这个卖点，也都
装着一堆看起来像是从地里长出来的颜色。一页北欧的灰和一页侘寂的陶土，远看很容易认错。

但它们不是一回事，只要知道该往哪里看，差别一点也不微妙。**北欧的光来自白与蓝；侘寂的光来自
陶土与木料。** 其余的一切都从这一句话推出来。

---

## 一、先说结论

北欧是**冷、浅、干净、平整**的。侘寂是**暖、有质感、更暗、刻意不完美**的。北欧的参照物是
日光、白墙与玻璃；侘寂的是土、火与时间。

这个差别同时体现在四个地方：

| | 北欧 | 侘寂 |
| --- | --- | --- |
| 色温 | 冷——每个中性色都是蓝的染色 | 暖——每个中性色都是陶土的染色 |
| 明度 | 高——平均 `L` 0.79 | 低——平均 `L` 0.61 |
| 彩度 | 平均 `C` 0.05，上限 0.12 | 平均 `C` 0.04，上限 0.05 |
| 质感 | 平滑、平面、不见痕迹 | 看得见——这正是这一族的目的 |

如果只能留下一句话来检验一个设计：**北欧是窗户开着的房间，侘寂是点着火炉的房间。**

---

## 二、并排对照

| | 北欧 | 侘寂 |
| --- | --- | --- |
| 底色 | 雪 `#F7F9FA`——近白，微偏蓝 | 石灰墙 `#E8E0D5`——非白，偏暖，有质感 |
| 主色 | 霜 `#E8EDF0`、冰川 `#C9D6DE`、峡湾 `#9FB6C4`、深峡湾 `#6B8FA3` | 沙 `#C9BBA6`、陶土 `#A08C7D`、苔 `#7D8471` |
| 强调色 | 陶土橘 `#D9A38F`、桉木 `#A9BC8F`、芥末 `#E3C46A` | 树皮 `#8C6D5B`、林 `#4A5A45` |
| 文字 | `#2E3A40`——蓝黑 | `#3B342E`——褐黑 |
| 明度带 | `L` 0.63 – 0.94 | `L` 0.45 – 0.80 |
| 彩度带 | `C` 0.01 – 0.12 | `C` 0.03 – 0.05 |
| 独立色相 | 4 | 4 |
| 平均明度 | 0.79 | 0.61 |
| 平均彩度 | 0.05 | 0.04 |
| HSL 饱和度均值 | 34% | 16% |

有两行值得注意，因为它们与直觉相反。

**彩度**那一行说北欧才是更好看的那个家族——平均 `C` 0.05 对 0.04，上限 0.12 对侘寂的 0.05。
这与通常的预期正好相反。它之所以成立，是因为侘寂完全靠色相和明度达成效果：陶土在 `C` 0.03
仍然一眼就是土色，因为色相干了全部的活。北欧不得不把彩度稍微推高一点，因为它的色相
更冷，而冷色在 `C` 0.02 时就是会消失。

**HSL 饱和度**那一行说的正好相反：34% 对 16%。这是 HSL 的盲点在实际使用中的表现。侘寂的颜色
HSL 饱和度只有 8% 到 29%，因为 HSL 是拿最亮的通道算的，而一段发闷的米色最亮的通道很高。北欧的
蓝色在 HSL 口径下保留了更多饱和度，因为蓝在三个通道上都很暗。**比较这两个家族时请看 OKLCH 的
彩度，不要看 HSL 的**——见[怎么看懂一块色板](../../1-overview/02-reading-a-palette/cn.md)。

## 三、真正的差别在哪

### 3.1 光从哪里来

北欧最深的主色是深峡湾，`L` 0.63；它的底色是雪，`L` 0.98。整块色板住在明度范围的上三分之一，
而那几个蓝灰彼此的色相差不超过两度。效果是一页读起来像从上方受光——北向窗户的那种光。

侘寂最深的主色是林，`L` 0.45；底色是石灰墙，`L` 0.91。它的色相从 52° 排到 138°——树皮、陶土、
苔——彼此不像北欧那几个蓝那样挨得那么近。效果是一页读起来像从低处受光——火、灯，或者地面反
上来的一点暖光。

这差别拿照片一拍就出来，而拿色值清单看是看不出来的。

### 3.2 明度上的落差

平均明度差了 0.18——0.79 对 0.61。在感知上这是一个很大的落差。它意味着北欧界面平均而言明显更
亮、更通透，而侘寂的界面更靠近中段，视觉分量更重。

它也意味着这两族不能共用同一个底色。雪 `#F7F9FA` 挨着石灰墙 `#E8E0D5` 不是微妙的差别，读起来
就是两个不同的房间。

### 3.3 文字色，以及它说明了整个页面

北欧的墨是 `#2E3A40`，色相 230°——蓝黑。侘寂的墨是 `#3B342E`，色相 63°——褐黑。两者明度几乎
相同（`L` 0.34 对 `L` 0.33），对白的对比度也几乎相同（11.70 对 12.23），却属于完全不同的世界。

这是最干脆的一项检验。**把你的正文摆出来，问它看起来偏蓝还是偏褐。** 北欧界面里的墨是冷的深
色；侘寂界面里的墨是暖的深色，而这份暖意会渗到页面上的一切。

### 3.4 各自不允许做什么

北欧的纪律是**明度与克制**。它禁止深色块，禁止大量饱和颜色，禁止一屏里出现超过一两个强调色。

侘寂的纪律是**质感与土**。它禁止任何看起来像工业制品的东西——不用纯灰，不用干净的合成白，不用
锐利的几何强调；彩度上限 0.05 把所有颜色都挡在"信号"之外。

这一点最清楚地体现在北欧的芥末 `#E3C46A`，`C` 0.12。它是一个完全体面的颜色，放在侘寂色板里则
根本不可能：那里一点彩度余量都没有。那么干净的一个黄，读起来是工业的，不是土地的。

## 四、怎么选

选**北欧**，当：

- 内容是信息——文档、看板、医疗、开发者工具
- 受众需要觉得这个产品干净、当代、可信
- 界面要挨着大量留白或大量内容
- 产品想看起来像一件仪器，而不是一件物

选**侘寂**，当：

- 产品关于材料、手艺、食物、家具，或某种生活方式
- 品牌想显得手作、陈旧、有根基
- 页面应该像一个房间，而不是一块屏幕
- 受众买的不只是东西，还有故事

一个好用的决胜题：**北欧是光源，侘寂是表面。** 如果设计的问题是"这里是什么光？"，你要北欧；
如果是"这是什么东西做的？"，你要侘寂。

---

## 五、容易混的地方

**"都是低饱和，无所谓啦。"** 低饱和是共有的，色温不是。先把色相钉死，再谈别的。低彩度的蓝灰
是北欧，低彩度的米灰是侘寂。两种都放进去，就成了第三种东西，而且通常只是发浑。

**"侘寂就是深一点的北欧。"** 不是。侘寂最深的颜色是 `L` 0.45，在北欧整条明度带之下。北欧没有
"森林绿"这个版本；侘寂也没有"雪"这个版本。

**"北欧降点彩度就是侘寂。"** 把陶土橘 `#D9A38F` 降彩度，得到的是一个发闷的橙，不是陶土。两个
家族的差别在色相，不只在彩度。北欧的色相范围是冷的、窄的；侘寂的是暖的，铺在三种不同的棕与绿
上。

**"两个都是北欧那边的。"** 侘寂是日本美学，与茶道和日本陶艺有关。这两种传统共享一点克制，除此
之外一无所有——没有共同的语言，共同的物件，共同的美学观。北欧一侧的来历见
[北欧 —— 这套颜色的来历](../01-nordic-origin/cn.md)；侘寂一侧见
[侘寂 —— 这套颜色的来历](../../6-wabi-sabi/01-wabi-sabi-origin/cn.md)。

## 六、混着用

两者可以共用一页，混用时接缝必须刻意。诀窍是：它们是相邻，不是调和——把北欧冷而浅的底对着
侘寂暖而有质感的底，让差别成为重点。

一种常见而且有效的排法：**界面用北欧，材料用侘寂。** 导航、表格、表单控件、图表全部在雪色和
蓝色阶上；照片、产品图、样本色块、引言放在陶土与树皮里。暖的一侧承载物质世界，冷的一侧承载
信息。

不成立的是交替使用——一张侘寂卡片、一张北欧卡片、一行侘寂、一行北欧。交替读起来是噪音，因为
每换一次就是换了一个房间。

如果要混，守两条硬规矩：

- **绝不调和两种中性色。** 别做一个"折中灰"，一半蓝一半米。那会两头不靠，而且跟任何东西都对不
  上。
- **两种文字色分开。** 北欧的文字仍是 `#2E3A40`，侘寂的文字仍是 `#3B342E`。同一段文档里出现两种
  正文色，不用想也知道会像出了错。
