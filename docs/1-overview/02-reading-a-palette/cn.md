# 怎么读一套色板

---

这本书里每个系列都用同样的三张生成表来记录：色板、色域带、色阶。这篇讲怎么读它们——更实用
的是，讲怎么拆解你遇到的任何色板，包括你自己的。

所有数字都出自 `scripts/palette.mjs` 对 `data/palettes.json` 的计算。表里没有任何手敲的数字，
这正是意义所在：如果表里说某个颜色不达标，那它就是不达标。

---

## 一、色板表

每个系列的文章开头都有这样一张表：

| 列 | 告诉你什么 |
| --- | --- |
| 色块 | 颜色本身 |
| 名称 | 这个系列里通用的名字 |
| 色值 | 可复制的十六进制 |
| 角色 | 这个颜色的职责——见下一节 |
| HSL | 色相、饱和度、明度——大多数工具显示的东西 |
| OKLCH | 感知明度 `L`、彩度 `C`、色相 `H`——这本书用来推理的东西 |
| 白字 / 黑字 | 该文字色压在这个填充上的 WCAG 对比度，以及达标的等级 |

最后两列是最实用的。比值 4.5 以上，正文可达 AA；3.0 以上，大字号与图表色条、焦点圈这类非文字
元素可达 AA；7.0 是 AAA。低于 3.0，这组颜色搭配只配做装饰。

这两列要成对读：哪边更大，就说明这个填充上该压哪种文字。马卡龙的柠檬 `#FFF1A8`，对白字 1.30、
对黑字 16.13——所以它只配黑墨，永远不配白字。霓虹的品红 `#FF2E88`，对黑 6.00、对白 3.50——白字
在数字上"可用"，但看上去仍然不对，因为整个系列是按深色底设计的。

---

## 二、角色

这本书里每个颜色都带六种角色之一。角色跨系列通用；不同的是每个系列往各角色里放几个颜色。

| 角色 | 职责 | 硬规矩 |
| --- | --- | --- |
| `surface` | 一切背后的底 | 每板一个；不承载正文 |
| `base` | 主色——填充、标签、图表系列 | 浅色主色填充上不放正文 |
| `accent` | 表示"可以点"或"看这里"的颜色 | 定量配给——多数系列一个 |
| `support` | 结构性的深浅档，通常是某主色的深一档 | 搭结构，不用来强调 |
| `ink` | 正文 | 不做填充 |
| `muted` | 说明文字、元信息、禁用态 | 对它的用途而言对比度仍要达标 |

读一套陌生色板时，第一个问题不是"有哪些颜色"，而是"哪个是强调色、墨色是哪个"。一套里有三个
颜色都在当强调色，那就不是一套色板，是三个在吵架。

---

## 三、HSL、OKLCH，信哪个

工具显示 HSL 是因为它算起来便宜；对粗略的动作——"浅一点"、"绿一点"——它够用。它在这本书
关心的两处失灵。

第一，HSL 饱和度高估浅色。淡柠檬 `#FFF1A8` 报出*100% 饱和*，因为饱和度按最亮通道计算；而它的
OKLCH 彩度只有 0.09。一个马卡龙粉和一个孟菲斯粉可以都写着"饱和 85%"，实际色彩量差三倍。

第二，HSL 明度不是感知明度。HSL 明度 50% 的黄远比 50% 的蓝看着亮。OKLCH 的 `L` 修正了这一点，
所以这本书的色阶按 `L` 等距走档，看起来才真的等距。

这本书的规矩：**明度在 OKLCH 里动，色相在 HSL 里 sanity-check，HSL 饱和度整个忽略。**

---

## 四、色阶

色阶是同一个主色沿 `L` 走五档——浅两档、本色、深两档——彩度与色相保持不动。超出 sRGB 色域的
档沿彩度轴拉回，方向是对的：颜色仍然看得出是同一个色相。

读色阶要读出一份预算表。浅端是大面积表面允许用的；深端是文字与边框允许用的；中间才是你当初
选的那个颜色。各系列的色阶给出的东西不一样：

- 马卡龙的色阶每档都浅——这个系列把明度预算全花在"浅"上。
- 莫兰迪的色阶在近灰里走档——扩展这个系列意味着新的明度，不是新的颜色。
- 孟菲斯的色阶从头吵到尾——想靠加白来让孟菲斯色闭嘴是办不到的。
- 霓虹的色阶就是发光感的做法：同一色相的浅一档，看起来就是光晕。

---

## 五、色域带

色域带是这个系列的脚印：主色占据的 `L` 区间与 `C` 区间、独立色相数、均值。两个数字干了大部分
的活：

- **平均明度**——这个系列垂直方向坐在哪。0.87（马卡龙）对 0.61（侘寂），是"几乎全是浅色"和
  "住在中段"的差别。
- **平均彩度**——这个系列花掉多少颜色。0.03（莫兰迪）对 0.19（孟菲斯），是耳语和喊叫的差别。

色板走形——加了一个"更好看"的蓝、为一条横幅加了第二个强调色——最先在色域带上显形：一个点
冒出 `C` 上限，这个系列就开始溶解了。

---

## 六、拆解任意色板的方法

拆一套不是你做的色板——竞品、品牌规范、接手的主题——按这五步：

1. **找底。** 大面积最浅的那个颜色是 surface；记下它是纯白、带色偏、还是深色。其余一切相对它
   评判。
2. **找墨。** 正文实际用的颜色——不是 `#000000`，除非它真是。墨色比任何单个颜色都快地告诉你
   这个系列的温度。
3. **数强调色。** 出现在按钮、链接、激活态上的颜色。一个，是系统；两个，需要理由；三个，是
   事故。
4. **算色域带。** 主色的 `L` 与 `C` 区间。和这本书里的系列对照——野外的多数色板都贴着其中之一，
   或卡在两个之间。
5. **查你真正会用的组合。** 文字压 surface、文字压 accent、accent 压 surface。三个对比度抓住
   要紧的失败；全矩阵抓到的多数是没人会发布的组合。

第 4 步是这本书七个系列值得记住的原因：它们是地标。一旦你能说出"这是莫兰迪， bolt 上了一个
孟菲斯强调色"，你就既知道它里面什么能用，也知道什么会坏。
