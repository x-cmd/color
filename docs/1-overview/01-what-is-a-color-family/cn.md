# 什么是色系风格

---

色板是一列颜色。**风格**是那条规则——说清哪些颜色该在一起，以及每个颜色允许出现在哪里。

这个区别比听起来要紧。两个团队都说"我们用马卡龙"，做出来的东西可以完全不像，因为其中一个
说的是一组色卡，另一个说的是一整套系统。色卡是容易的部分；系统才是真正要学的东西，也正是
它让你能做出新的东西、同时还看得出是同一个系列。

这里记录七个系列——马卡龙、莫兰迪、瑞士中立、北欧、侘寂、孟菲斯、霓虹。它们共用同一套描述
框架，也就是下面这四条约束。

---

## 一、四个约束

### 1.1 一条明度带

一个系列里的每种颜色，都落在若干个已知的感知明度台阶上。用 [OKLCH](https://bottosson.github.io/posts/oklab/)
的说法就是 `L`——大致是"有多亮"，0 是黑，1 是白。

明度带是一个家族在你还叫不出它名字之前就能被认出来的原因。马卡龙落在 `L` 0.79 到 0.95 之间：
一切都是亮的，除了文字不允许有深色。瑞士中立的带宽得多（0.32 到 0.97），因为它由一条灰阶
搭成，但这条灰阶是定死的——你从里面挑台阶，而不是自己另造。

明度带不等于"整体都是浅色"。它是对*哪几种浅*的承诺。

### 1.2 一条彩度上限

彩度（OKLCH 里的 `C`）是一个颜色"有多少颜色"，与它有多亮、多深无关。它是颜色和它自己的灰度
版本之间的差别。

各系列在这条上的差别，比在明度上的差别大得多。莫兰迪的颜色落在 `C` 0.01 到 0.06 之间——
比周围的灰多一点颜色而已。孟菲斯跑在 0.12 到 0.25，那是颜色开始叫唤的区间。

有些系列根本没有上限，因为纪律来自别处。瑞士中立只允许一种有彩色的颜色——它的信号红，真正
要紧的规则是*只有一个*。

### 1.3 一组色相

允许用哪些色相，允许几个。马卡龙的主色横跨七个色相，冷暖大致平衡。瑞士中立允许一个。

这条约束最常被跳过，也正是它能防止一个系列走形。放着不管，色板就会累积：为了链接再加一个蓝，
为了警告再加一个红，一两个版本之内，这个系列就没了。

### 1.4 角色纪律

颜色到底允许出现在哪里。这本书里的每个色板都会把颜色分成若干角色，角色自带规矩。

| 角色 | 干什么用 | 规矩 |
| --- | --- | --- |
| `surface` | 页面或画布的底 | 不承载文字 |
| `base` | 主色——色块、标签、插图、图表里的系列 | 浅色块上不承载正文 |
| `accent` | 唯一被允许表示"可以点"的颜色 | 一屏一个 |
| `support` | 辅助色阶，通常是某个主色的深一档 | 用来搭结构，不用来强调 |
| `ink` | 正文 | 不做填充 |
| `muted` | 说明文字、元信息、禁用态 | 对比度仍然要达标 |

角色纪律是*系统*与*收藏*的分界线。一堆马卡龙色卡是六个色值；一套马卡龙系统会说明哪个是强调
色、墨色永不做填充、底色始终接近白。

## 二、"浅"不构成一个系列

马卡龙和莫兰迪都是浅色，这是它们全部的相似点，而它不够用。

莫兰迪把每个色相都往灰里拽：它的中性色是带暖调的灰，不是纯灰，最饱和的一个颜色是深陶土。
马卡龙保住色相的可辨识度——一眼就能叫出名字，粉、薄荷还是柠檬——并把颜色花在装饰上，而
莫兰迪把颜色花在材质上。

还有一处差别容易在色值表里看漏，值得单独点出来：莫兰迪的墨色是暖的（`#3F3A38`），马卡龙的
是偏梅的（`#4A4045`）。文字颜色是家族的一部分，不是游离在外的中性色。

## 三、这本书用的词

**HSL** 是大多数工具给你看的东西，但要知道它的盲区。HSL 的饱和度是按最亮的通道算的，于是浅黄
`#FFF1A8` 会算出*100% 饱和*——而它的 OKLCH 彩度只有 0.09。HSL 用来挑"更浅一点的薄荷"没问题，
但它衡量不了颜色到底有多彩。

**OKLCH** 是这本书所有数字的出处。`L` 是明度，`C` 是彩度，`H` 是色相（角度）。它感知均匀，
等距的步长看起来就是等距的——这个性质值得多打这几个字母。

**对比度**按 WCAG 的算法算：两个颜色相对亮度之比，取值 1 到 21。4.5 是正文可读的下限，3 是大
字号以及图表色条、焦点圈这类非文字元素的下限。

**色域带**是这个系列的颜色所处区间的说法，写成 `L` 与 `C` 两段范围。**色阶**是从一个主色派生
出来的深浅档：在 `L` 上等距移动，彩度与色相保持不变。

这里所有数字都由 `scripts/palette.mjs` 从 `data/palettes.json` 算出，因此文章里的表格不会和它们
描述的色板脱节。

## 四、系列怎么组织

每个系列四篇：

| 文章 | 讲什么 |
| --- | --- |
| **来历** | 这个系列是什么、从哪来、视觉语法，以及它不是什么 |
| **色板** | 颜色本身、它们的数值、色阶，以及怎么派生 |
| **对比** | 和相邻系列并排对照 |
| **应用** | 什么时候好用、什么时候会坏，以及怎样守住它 |

对比文章连成一个环——马卡龙比莫兰迪、莫兰迪比瑞士中立、瑞士中立比北欧、北欧比侘寂、侘寂比
孟菲斯、孟菲斯比霓虹、霓虹再回到马卡龙。于是每个系列都和左右两侧"夹住"它的邻居比较，而真正
需要做决定的地方，往往就在这两侧。

## 六、几个坑

- **只抄色值，不抄明度带。** 马卡龙色板放到深色底上，就不是马卡龙色板了——那条带是按浅底算的。
- **把系列名当成一个颜色。** "莫兰迪"不是某种色号，它是一段明度范围和一条关于"允许多少颜色"
  的规则。
- **让色板一路累积。** 色相集合是防止系列走形的那条约束。每多一个不在集合里的颜色，都是一次
  需要有意识的决定。
- **指望规则换个场景还成立。** 这些明度带是按浅底上的界面与编辑页面算的。投影仪、印刷品和
  暗色模式是三个不同的问题。
