# 瑞士中立的实际应用

---

色板是容易的一半。瑞士中立难的地方在于，它要求你用排版和版式把活干完，并且堵掉了"用颜色
掩盖一个坏决定"这条退路。

这里讲它在哪里好用、组件具体长什么样，以及它在什么地方会坏。

---

## 一、什么时候好用

**出版与编辑版面。** 杂志、年报、展览图录、节目单。瑞士风格本来就是从这类工作中长出来的，
这个家族至今仍然合身：一版跑字、几根分隔线、一段用红色拉出来的引文，以及由照片承担全部
色彩的版面。版面里没有颜色，反而让图像显得更饱和，而这往往正是想要的效果。

**文档。** API 参考、产品手册、规格说明、更新日志。文档是这个家族最干净的应用场景，因为
文档的层级异常严格：标题、正文、提示、警告、代码示例。每一级都是一个层级，而瑞士中立的灰阶
给了每一级一个颜色。不需要第二个强调色，因为第二层级的手段是更重的字重，不是另一个色相。

**建筑与设计事务所。** 尤其是走理性路线的建筑、工业设计、平面设计事务所的作品集网站。这里的
色板在做一件有点特别的事：它刻意地安静，好让作品成为页面上唯一有性格的东西。一个通篇红色
标题的作品集，是一个在自说自话的作品集。

**数据报告。** 年度业绩、研究摘要、公共统计——任何需要让一条系列从其他系列里站出来的场景。
这是这个家族最锋利的用法，因为要求恰好只有一条：**只有一条**必须被看见。瑞士中立可以把其余
系列全放进灰色，让一条是红的，而且不必为此发明一套八色的分类色板。

**票务与导视。** 标识牌、时刻表、站台标记、票务与预订系统。这里的约束是物理的：标识要在
远处、在坏光线下、被一个正在移动的人读懂。真灰在任何观看条件下都给出可预期的对比度，而
单个红色标记之所以成为航空和公共交通里的经典信号色，理由也在这里。

## 二、界面上

### 一张表

瑞士中立最有代表性的组件，也是最常被做错的一个。

规矩是：**结构由分隔线承担，不由色块承担。** 这个家族里的数据表是白底、表头下和各行之间一根
`#E0E0E0` 发丝线，没有横向斑马纹。用 `#F5F5F5` 做隔行底色是可行的，但那是妥协——它在用一级
表面去干一根细线能干得更好的活，还多出一份视觉重量。

| | 角色 | 颜色 |
| --- | --- | --- |
| 列头 | 文字 | `black`，或小一号时用 `deep` |
| 表头分隔线 | 分隔 | `rule` `#E0E0E0` |
| 单元格文字 | 正文 | `black` 或 `deep` |
| 数字单元格，右对齐 | 正文 | `deep`，等宽数字 |
| 行分隔线 | 分隔 | `rule` `#E0E0E0` |
| 高亮行 | 标记 | 只把 `signal-red` 放在数值上，绝不用整行填充 |

两个细节要紧。数字右对齐并用等宽数字，让位数在竖直方向上对齐——这是一个用排版解决可读性
问题的例子，也正是这个家族赖以成立的那种替换方式。高亮的那一行标记的是**数值**，不是整行：
一行白底上的红数字是一个信号；一整行红色是设计没招了。

### 一张图

这个家族里的图通常是灰的加一条红色，而这是特性。必须让一条系列从其他系列里站出来的图有个
真问题：多数分类色板的解法是给每条系列一个不同的颜色，结果是重要的那条并没有比其他的重要
多少。瑞士中立解决得干净：其余系列用 `secondary` 或 `deep`，要紧的那条用 `signal-red`。

柱状图最适合这样用，因为长度已经是编码了，颜色正好空出来承担强调。折线图更难——好几条线
的时候，1 像素的灰线很难跟住，所以这个家族通常要么减到两三条线，要么用 `deep` 画次要线、
用红线画主线。

网格线是 `rule` `#E0E0E0`。坐标轴标签是 `secondary`，字号要小到它们读起来像注解而不是像数据
——如果小到看不清，那就该是看不清，这种尺寸就不该出这张图。聚焦环或交互高亮用红色。

有一件事要当心：红色作为图表颜色是个带信号的用法。如果一根红柱会被读成"坏"或"亏"，那这条
红线就应当基于别的理由来选——要紧的那条、当前周期、图表真正的主题；如果和这个冲突，该改的
是图的讲法，而不是换一个色相。为了表示"负值"再加一个更柔和的强调色，会破坏这个家族。

### 一个提示框

提示框是强调色真正挣到位置的地方，也是它最常被浪费的地方。

一个守规矩的提示框：`panel` `#F5F5F5` 底，一行更小更重的 `deep` 或 `black` 标签，正文用
`deep`，左边一道 2 到 3 像素宽的 `signal-red`。红色是标记，不是底色，而且只出现一次。

一个破坏家族的提示框：红色标题、红色图标、红色左边框，再加一个红色的"了解更多"链接。一个
组件里四个红，说明强调色什么也没说，读者得自己去分辨哪部分可以点。

还要注意提示框里**没有**什么：带色调的底色。需要和页面区分开的提示框是 `panel`，不是一个颜色。
如果提示框还需要和别的提示框区分开，那是第二层结构——更重的线、嵌套的面——不是第二个色相。

### 一个表单

表单是这个家族的规矩咬得最紧的地方，因为表单想要用颜色表示状态。

瑞士中立的表单：字段放在 `paper` 上，标签用 `deep`，帮助文字用 `secondary` 且字号要读得
清，字段描边 `#E0E0E0`，框内文字 `black`。主按钮是 `black`，不是红色。这是有意为之：白底上的
黑按钮有 21.00 的对比度，不可能被忽略，而把强调色空出来留给信号，正是那唯一的红值得存在的
理由。

校验是最有意思的地方。无效字段需要标记，而这个家族只有一个强调色。答案不是第二个红，而是
把现有的红用在字段描边和错误信息上，再加一个图标，再加信息文字本身。一屏只一个红，意味着一
个表单里有两个错误时，其中只有一个能是红的——这是个实打实的约束，而更好的解法是滚动并聚焦
到第一个错误，而不是再加一个橙色。

禁用态用 `panel` 上的 `secondary`，或者 `paper` 上的 `secondary` 文字配 `rule` 描边。它应该
看起来"不可用"，而不是看起来"有颜色"。

### 导航与版式

顶层导航是 `paper` 上的 `black` 或 `deep`。当前页用 `signal-red` 标记——要么是标签本身，要么
是下面一道红线。没有悬停色；悬停变成 `deep`，当前态才是红的。

网格是齐左的、固定栏数的。面板是 `#F5F5F5`。分段用 `#E0E0E0` 分隔线。一页既没有线、只有
留白，同样是合法的瑞士中立，而且往往更好。

## 三、品牌与印刷

在印刷上，这个家族在一个方面更宽容，另一个方面更苛刻。

宽容的一面：真纸有纸色，灰会落在纸上。瑞士中立吃得开，因为它的灰本来就是中性的——暖调的灰落在
暖纸上显得是有意为之，冷调的落在同一张纸上就像出了错。这正是莫兰迪和北欧在非涂布纸上需要
小心、而瑞士中立不必的原因。

苛刻的一面：网格必须是对的。在印刷分辨率下，栏没对齐是真的错误，不是四舍五入的差别，而且没有
颜色能替你分散注意力。正确的工作顺序是先把字排好，用黑色排，然后再决定红放在哪儿。

印刷里的红：一句引文、一个统计数字、一个章节标记、地图上的一个点。每跨页至多一个。印刷上的
诱惑是在一本薄册子里每一跨页都用上——然后到第十跨页，读者已经不再注意它了。到处都出现的红，
等于哪里都没出现的红。

## 四、数据可视化

数据是这个家族最有价值、也最常被放弃纪律的地方。

要紧的规矩是：**颜色只用一次，而且用在那件要紧的事上。** 具体说，一份有七条系列、其中一条
是主角的报告：

- 主角系列：`signal-red`，满饱和
- 背景系列：噪音的那些用 `secondary`，读者可能需要比较的那些用 `deep`
- 网格线与坐标轴：`rule` 和 `secondary`
- 其余：黑与白

对于七条系列、其中**没有**一条是主角的报告，诚实的答案是这张图有结构问题——读者没法跟住
七个灰。解法是减少系列、换一种编码（小倍数图、一张表、带直接标注的堆叠条），或者换一套不是
瑞士中立的色板。这个家族救不了一张坏图；它只会让坏得更明显。

直接标注胜过图例。这个家族里的图例是一小块灰字，读者得把视线从图上移开去解码它。把线在末端
直接标上，代价是一个 `deep` 的标签，省掉的是整个图例。

---

## 五、什么时候会坏

**需要区分多种状态的时候。** 错误、警告、成功、信息。这个家族只有一个强调色，而一个强调色
装不下四种意思。如果你的产品真的需要绿、琥珀和橙，那它需要一套有三个强调色的色板——而且应该
别再假装不是。把瑞士中立硬套到一个有状态语义界面上，代价是所有东西最后都成了灰，而灰也就
不再意味着任何东西。

**内容需要温度的时候。** 靠手艺、用心、家庭、手作来卖东西的产品，在真灰里会读起来冷、读起来
机构化。莫兰迪或侘寂会服务得更好。

**强调色需要能被当正文读的时候。** `signal-red` 压 `paper` 是 4.00，正文尺寸下不过 AA。红色的
链接在正文尺寸下是一次对比度失败。红字必须大而且粗。

**没有网格的时候。** 色板不会自己造出层级。一个没有栏、没有线、没有间距刻度的版面，填上真灰，
读起来是没做完——因为这个家族的灰本来应该是系统的*结果*，而这里没有系统。这也是瑞士中立最常
被说成"无聊"的原因，而诊断结果几乎总是版面而不是色板。

**在没校准的屏幕上。** 真灰假定显示器是中性的。一台偏蓝很多的笔记本，或者一间暖光里的投影
仪，会给整页染上色偏。瑞士中立在这方面比带色调的家族更吃亏——后者自带色温，怎么看都像是
有意为之。

**在深色底上。** 那条明度带是按浅底算的。这些颜色没法干净地反相——`#E0E0E0` 的线在深底上
变成一根发光的线，`#FFFFFF` 的纸变成一个很吵的亮块。瑞士中立没有深色模式；它只有浅色模式，
就这些。

**在密集看板里。** 一墙的小数字、很多图、很多状态，是颜色真正承重的环境，而这里颜色不够用。
这个家族在"只有一样东西要看"的时候才成立。

## 六、一份检查清单

发布一个瑞士中立的设计之前，走一遍这份清单。

- 屏幕上是不是恰好**一个**有彩色的颜色，它是不是只表示一件事？
- 设计里的每一级灰，是不是那六级梯子里的某一级，或者是一级刻意派生、且彩度守在零的？
- 正文是不是 `black` 或 `deep`？任何 `secondary` 的文字是不是够大够粗？
- 任何红色文字是不是够大或够粗——红压白是 4.00？
- 层级是不是由字体和留白做出来的，颜色只标那个例外？
- 分隔是不是由线做的，而不是由带色的填充做的？
- 有网格吗？字是不是落在网格上？
- 把红去掉，这一页还讲得通吗？应该讲得通——然后那个红应当自己显出来，成为唯一值得指的东西。
- 有没有什么地方是用颜色去干一根线、一个字重或一段留白本来能干的活？
